# Pig Game

A two-player dice game that runs in the browser. Roll the dice, collect points, and be the first to reach 100.

## How it works

- Players take turns rolling a dice
- Each roll adds to your current score
- Roll a 1 and you lose the current score, and the turn passes to the other player
- Hit "Hold" to bank your points and end your turn
- First player to reach 100 wins
- "New game" resets everything

## Built with

HTML, CSS, vanilla JavaScript

## Run it

Clone the repo and open `index.html` in your browser.
